# Tag

A mono chip for a skill, technology or filter. Static by default; pass `onClick` to make it a toggle (`selected` paints it `primary-soft` / `primary-ink`).

- Provide: `children` (the tech name, written as the project writes it: "Next.js", "MongoDB", "Express.js").
- Use for skills lists and project filters. Keep to one line; never more than ~8 per card.
- Don't use a Tag as a status — that is `StatusBadge`.
