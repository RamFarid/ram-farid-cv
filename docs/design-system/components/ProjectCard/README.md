# ProjectCard

A portfolio entry: 16:9 media, mono meta line (`kind` · `year`), title, one-sentence description and up to six tech `Tag`s. With `href` the whole card is a link and lifts with `shadow-glow` on hover.

- Provide: `title`; optional `description`, `kind`, `year`, `tags`, `href`, `image` + `imageAlt`. Without `image` the media shows a mono monogram (`monogram` or the title's first two letters) — a placeholder, replace with a real screenshot before launch.
- Description: what it is and who it is for, in one sentence. No "A website that…" filler.
- Grid: 1 column under 640px, 2 up to 1024px, 3 above; `space-5` gaps.
