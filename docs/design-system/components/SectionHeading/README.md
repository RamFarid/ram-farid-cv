# SectionHeading

Opens every page section: a mono `eyebrow` (with an optional `index` like "02"), the `h2` title, and an optional lead in `ink-muted`.

- Provide: `title`; optional `eyebrow`, `index`, `description`, `level` (default 2), `align`.
- Eyebrow: one or two words, the section's name ("About", "Projects", "Contact"). In Arabic the eyebrow drops uppercase and tracking automatically under `dir="rtl"`.
- Title: a plain statement in sentence case, no trailing period.
