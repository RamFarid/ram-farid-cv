# StatusBadge

A short status with a colored dot: availability in the hero, or the result of a form. The word carries the meaning — color is a second signal, never the only one.

- Provide: `children` (2–4 words) and `tone`: `success` (teal — "Available for work"; its dot pulses unless reduced motion), `warning`, `danger`, `neutral`.
- One per area. Don't stack several badges as decoration.
