# Logos

The logo: "Ram" cutting through a giant R, all in violet. Outlined to paths in Readex Pro Bold. One logo for English and Arabic.

- `ram-logo-on-dark.svg` — R #a25bff (`primary`), word #dcc6ff (`logo-word`, Dark). On `bg` / `surface` in Dark.
- `ram-logo-on-light.svg` — R #a25bff, word #5a1fb5 (`logo-word`, Light). On Light grounds.
- `ram-icon.svg` — the sliced R alone, #a25bff on a #0b0910 rounded square. Favicon, app icon, avatar, nav. Works on either theme.

Minimum size: lock-up 48px tall; icon 16px. Clear space: one stem width of the big R.
